# Phishing Awareness Analysis

## Overview

Phishing Awareness Analysis is a Python-based cybersecurity project designed to identify potential phishing indicators within email messages. The system analyzes email content, detects suspicious patterns, calculates a risk score, and classifies messages as Safe, Suspicious, or Malicious.

The project demonstrates fundamental concepts of phishing detection, email security analysis, and risk-based threat assessment.

## Features
- Suspicious keyword detection
- URL and shortened-link analysis
- Risk score calculation
- Sender-domain mismatch detection
- Urgency trigger identification
- Password request detection
- QR code phishing detection
- Callback scam detection
- Social engineering indicator analysis
- Automated threat classification

## Technologies Used
- Python 3
- Regular Expressions (Regex)

## How It Works

The system analyzes email content for multiple phishing indicators and assigns a risk score based on detected threats.
Based on the final score, emails are classified as:
- SAFE
- SUSPICIOUS
- MALICIOUS
The application also provides recommended actions and a detailed phishing triage report.

## How to Run
1. Open the project folder in a terminal.
2. Run the following command:
python phishing_analysis.py
